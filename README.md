# RAG Physics Textbook System

A Retrieval-Augmented Generation (RAG) system that allows users to query physics, chemistry, and biology textbooks using natural language. The system automatically searches across all subjects and retrieves the most relevant text chunk from any of the textbooks.

## Features

- **Multi-Subject Search**: Automatically searches across Physics, Chemistry, and Biology textbooks
- **Vector Database**: Uses ChromaDB to store and search through textbook content
- **Semantic Search**: Employs sentence transformers for intelligent text retrieval
- **Query Rephrasing (LLM)**: Rewrites user queries into concise, textbook-style questions using `google/flan-t5-small`
- **Reranking**: Reorders retrieved results with `cross-encoder/ms-marco-MiniLM-L-6-v2` and selects the top 3
- **Lightweight Answer Generation**: Generates a concise answer using `google/flan-t5-base` (fallback to `flan-t5-small`), CPU-friendly
- **Web Interface**: Modern React frontend with dark/light mode and sources viewer
- **Sources Metadata**: Displays collection, page number (if available), similarity, rerank score, and snippet text

## Setup Instructions

### 1. Backend Setup

First, set up the Python backend:

```bash
cd backend

# Install dependencies
pip install -r requirements.txt

# Ingest PDFs into ChromaDB (only needed once)
python ingest.py

# Start the Flask server
python server.py
```

The server will start on `http://localhost:5000`

### 2. Frontend Setup

In a new terminal, set up the React frontend:

```bash
cd react-frontend

# Install dependencies
npm install

# Start the development server
npm start
```

The frontend will be available at `http://localhost:3000`

### 3. Testing the System

You can test the backend server using the provided test script:

```bash
cd backend
python test_server.py
```

The test prints status code, original/rephrased query, a snippet of the answer, and a compact list of sources.

- `GET /api/health` - Health check
- `GET /api/collections` - Get available textbook collections
- `POST /api/search` - RAG flow: rephrase → retrieve (top-5/collection) → rerank → answer

## How It Works

1. **Ingestion**: PDFs are processed and chunked by sections, then embedded and stored in ChromaDB
2. **Query Rephrasing**: The user query is rewritten into a concise, textbook-style question using `google/flan-t5-small`
3. **Multi-Collection Retrieval**: Retrieve top 5 candidates per collection (Physics, Chemistry, Biology)
4. **Reranking**: All candidates are scored with `cross-encoder/ms-marco-MiniLM-L-6-v2`; take the top 3
5. **Answer Generation**: The rephrased query and top 3 sources are passed to `google/flan-t5-base` (fallback to `flan-t5-small`) to produce a concise answer
6. **Display**: Frontend shows the final answer, rephrased query, and a sources section with collection name, page number, similarity, and rerank score

## Models

- **Embeddings**: `all-MiniLM-L6-v2` (SentenceTransformer via ChromaDB)
- **Query Rephrasing**: `google/flan-t5-small`
- **Reranking**: `cross-encoder/ms-marco-MiniLM-L-6-v2`
- **Answer Generation**: `google/flan-t5-base` with fallback to `google/flan-t5-small`

## Key Benefits

- **CPU-Friendly**: Uses lightweight FLAN-T5 models suitable for CPU-only environments
- **Better Answers**: Rephrasing and reranking improve retrieval quality and final answers
- **Rich Sources**: Sources include collection, page number (if available), distance, rerank score, and snippet

## Customization

- **Add New Books**: Place PDFs in the `data/` folder and update `BOOKS` in `ingest.py`
- **Change Embedding Model**: Modify the model in `ingest.py` and `server.py`
- **Adjust Chunking**: Modify the `chunk_by_section` function in `ingest.py`

## Troubleshooting

- **Server Connection Error**: Ensure the Flask server is running on port 5000
- **No Results**: Check that PDFs were properly ingested using `python ingest.py`
- **CORS Issues**: The server includes CORS headers, but ensure your frontend is on the correct port
